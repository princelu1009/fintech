# Financial quotient

### Q1. 台股上市櫃公司總數
整個台股上市櫃公司總共有幾 N 家，請問 N 的範圍？
1. N < 500
2. 500 < N < 1000
3. 1000 < N < 2000
4. 2000 < N < 3000
5. 3000 < N

> [!success]- 答案：3（1000 < N < 2000）
> 上市約 1000 家、上櫃約 800 家，合計約 1800 家。

### Q2. 台股每家公司的每日漲跌幅的限制
台股每家公司的每日漲跌幅的限制是正負百分之幾？（請寫數字即可，不加百分比）

> [!success]- 答案：10
> 2015 年 6 月起由 ±7% 放寬為 ±10%。

### Q3. 基本面名詞
Give the full names (in English) of the following terms: EPS, ROA, ROE, PER, PBR.

> [!success]- 答案
> - EPS：Earnings Per Share（每股盈餘）
> - ROA：Return On Assets（資產報酬率）
> - ROE：Return On Equity（股東權益報酬率）
> - PER：Price-to-Earnings Ratio（本益比）
> - PBR：Price-to-Book Ratio（股價淨值比）

### Q4. 基本面名詞之二
Give the full names of the following terms: PER, PBR.

> [!success]- 答案
> 同 Q3：PER = Price-to-Earnings Ratio，PBR = Price-to-Book Ratio。

### Q5. 股票殖利率
下列何者是對的？
1. 股票殖利率是長期存股的一項重要考慮因素。
2. 殖利率的計算，通常包含現金配息及股票配息。
3. 股票在除息後若無填息，則殖利率還是無法代表真正的收益。
4. 目前銀行的定存年利率大約是 1% 左右，而台股近年來的平均殖利率可以超過 3%。

> [!success]- 答案：1, 3, 4
> 1. ✅ 存股就是靠每年配息，殖利率是主要指標。
> 2. ❌ 一般講的殖利率是**現金**殖利率 = 現金股利 / 股價，不含股票股利（股票股利要看除權後的價格，不是直接收到的錢）。
> 3. ✅ 除息時股價會扣掉股利；沒填息的話，領到的股利只是被股價下跌抵銷，沒有真的賺到。
> 4. ✅ 定存約 1%，台股平均殖利率約 3–4%。
>
> ⚠️ 選項 2 是推論：也有網站把股票股利算進「總殖利率」，如果老師的定義不同，答案可能是 1–4 全對。

### Q6. 分析股票的四大面向
請問什麼是分析股票的四大面向？

> [!success]- 答案：基本面、技術面、籌碼面、消息面
> - 基本面：公司營收、獲利、財報（EPS、ROE、本益比…）
> - 技術面：股價與成交量的圖形和指標（均線、K 線、RSI…）
> - 籌碼面：誰在買賣（法人、主力、融資融券）
> - 消息面：新聞、政策、產業動態
